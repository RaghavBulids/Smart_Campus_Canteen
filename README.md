# 🍽️ Smart College Canteen System

A simple and interactive college canteen management system designed to improve ordering workflow and order tracking within a college environment.

The system provides separate interfaces for students and administrators, allowing streamlined food ordering, order management, and revenue monitoring.

---

## 🚀 Features

### 👨‍🎓 Student Side
- Student Login System
- Browse available food items
- Add items to cart
- Apply available discounts
- Place food orders
- Simple and user-friendly ordering workflow

### 👨‍💼 Admin Side
- Admin Login System
- View incoming orders
- Mark completed orders as **Done**
- Revenue tracking dashboard
- Order monitoring and management
